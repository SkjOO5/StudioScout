## 🚀 How to Use

### In Claude Code:
All plugins are now available as skills. You can invoke them by mentioning them in your requests, for example:

- "Review my changes for code quality"
- "Help me build a new feature"
- "Check this code for security issues"
- "Generate a commit message for these changes"
- "Simplify this component"

### Quick Commands:
- `/plugin list` - View all installed plugins
- `/plugin enable <name>` - Enable a plugin
- `/plugin disable <name>` - Disable a plugin
- `/plugin install <name>` - Install new plugins
- `/plugin remove <name>` - Remove a plugin
